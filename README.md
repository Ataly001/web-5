# Assignment 5 - JavaScript Basics

**Student:** Zhailybaev Ataly  
**Group:** SE-2530

## Description
This project contains 9 tasks about JavaScript basics, DOM manipulation, and events.

The main goal is to learn how JavaScript works with HTML elements and makes web pages interactive.

## Technologies
- HTML - page structure
- CSS - page design
- JavaScript - logic and interactivity

## JavaScript Features
- **Variables and Operators:** Using different data types and arithmetic operations.
- **DOM Manipulation:** Changing text, styles, and HTML elements using JavaScript.
- **Events:** Using mouse clicks, mouseover, mouseout, and keyboard events.
- **Calculator:** Performing basic math operations using JavaScript functions.
- **To-Do List:** Adding, completing, and deleting tasks. Tasks are stored temporarily in an array.

## How to Run
1. Download the project.
2. Open `index.html` in a browser.
3. Use the navbar to switch between tasks.
4. Open the browser console for Tasks 0 and 1.

## Project Structure
- `index.html`, `task1.html` - `task8.html` - HTML pages
- `style.css` - styles for all pages
- `script.js` - JavaScript functions for all tasks
